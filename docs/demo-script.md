# 2–3 minute demo script

Use the local demo and say explicitly that outreach is simulated and Band/Flexprice are not connected. Do not describe templates as live model output or public general mailboxes as verified buyers.

| Time | Screen / action | Narration |
| --- | --- | --- |
| 0:00–0:20 | Overview; switch Allco/Huasheng and return | One portal manages two separate industrial suppliers. Allco's first campaign targets US equipment manufacturers. Context and approvals stay with each business. |
| 0:20–0:45 | Product & ICP; capabilities; ideal customers | The supplier defines products, constraints, roles, target size, and buying signals. Unknown pressure limits and certification remain unknown. Adjacent segments and the profile require review. |
| 0:45–1:10 | Discovery run; Elliott or Link-Belt evidence | Real OEM candidates have primary citations, visible fit components, public roles, and source check results. Product relevance does not prove purchase intent. Contact/MX checks do not verify a mailbox. |
| 1:10–1:30 | Knowledge graph; query and inspect path | Kuzu stores actual directional relationships. A published person connects to a company and relevant product. Every endpoint is scoped to Allco. |
| 1:30–2:00 | Outreach; prepare A/B draft; edit/save/approve/dry run | Source-grounded sequences carry application context. The server requires approval of the exact version. Edits revoke approval. A dry run creates a receipt and consumes one local credit; no message is sent. |
| 2:00–2:20 | Pipeline and activity | Track qualification, RFQs, engineering review, quote, trial, and close. Each transition records its actor and time. Demo and user-reported outcomes are visible. |
| 2:20–2:40 | Credits / Integrations | The local ledger enforces credit limits and refunds failed jobs. Band and Flexprice are unconnected placeholders awaiting project credentials. The demo does not claim those bonuses. |
